# haakwahl.github.io
TRØNDER-SLEKT
Slektsbasen er bygget opp med utgangspunkt i mine foreldre Wahl og Volden på farsiden og Hansen og Laugen på morsiden i Nærøy og Kolvereid, samt min kone Lovise sine foreldre Eggan på farsiden i Trondheim, Orkdal og Rissa, og på morsiden Lien og Aaneng fra Vemundvik og Otterøy. Dessuten er aner til inngifte i mange tilfeller lagt til, som min fosterfar Tvedt sin slekt fra Lindås og Masfjorden, våre etterkommere sine aner på Romerike – Lillestrøm, Strømmen og Sørumsand – og Oslo, med navn som Johansen, Ødegaard og Sandberg.
Informasjoner er hentet fra bokugivelser fra f.eks. Nærøy, Kolvereid, Gravvik, Vikna, Høylandet, Overhalla og Grong, Jøa i Namdalen. 
Her er informasjon om bl.a. kjente slekter som Wendelboe, Sellæg, Melgaard, Bendixen, Peter Dass og mange flere.
